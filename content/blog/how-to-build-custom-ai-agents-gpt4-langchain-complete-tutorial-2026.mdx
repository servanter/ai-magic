## Why Build Custom AI Agents? (The Business Case)

Before diving into code, understand **why** custom agents matter:

### Real-World Impact
- **Customer Support**: AI agent handles 78% of routine inquiries (1 agent = 3 human agents at $120,000/year)
- **Data Analysis**: Agent processes 500 spreadsheets overnight (task that took analysts 2 weeks)
- **Content Creation**: Agent researches + writes + edits blog posts (10 posts/day vs. 2 posts/day human)
- **Code Review**: Agent catches 89% of security vulnerabilities before production

### Why Not Just Use ChatGPT?
**ChatGPT limitations:**
- No tool access (can't search web, read files, execute code)
- No memory (forgets after 1 conversation)
- No customization (can't add your company data)
- No automation (requires human prompt each time)

**Custom agents solve all this:**
- ✅ **Tools**: Connect to APIs, databases, external services
- ✅ **Memory**: Remember users, preferences, past interactions
- ✅ **Knowledge**: Train on your data (docs, policies, codebases)
- ✅ **Automation**: Run 24/7 without human input
- ✅ **Control**: Define behavior, guardrails, cost limits

**Cost comparison:**
- ChatGPT Plus: $20/month/user (no customization)
- Custom GPT-4 agent: $50-200/month (unlimited users, full control, integrated with your systems)

**When you need a custom agent:**
1. Task requires multiple steps (research → analyze → decide → act)
2. Need to connect to your internal systems (CRM, database, APIs)
3. Task repeats frequently (automate instead of manual each time)
4. Need context memory (remember user preferences, conversation history)
5. Require control (guardrails, cost limits, specific behavior)

Let's build the simplest possible agent: **a conversational AI that answers questions using GPT-4**.


### Step 1.2: Basic Agent Code

Create `basic_agent.py`:
```python
from langchain_openai import ChatOpenAI
from langchain.agents import initialize_agent, AgentType
from langchain.agents import Tool
import os

# Load API key
os.environ["OPENAI_API_KEY"] = "sk-your-key-here"  # Or use python-dotenv

# Initialize GPT-4
llm = ChatOpenAI(model="gpt-4-turbo", temperature=0.7)

# Define empty tools list (agent with no tools, just conversation)
tools = []

# Create agent
agent = initialize_agent(
    tools=tools,
    llm=llm,
    agent=AgentType.ZERO_SHOT_REACT_DESCRIPTION,
    verbose=True
)

# Test the agent
response = agent.run("What is the capital of France? Explain why it's significant.")
print(response)
```

**Run it:**
```bash
python basic_agent.py
```

**Expected output:**
```
> Entering new AgentExecutor chain...
The capital of France is Paris. It's significant because it's a global center of art, fashion, gastronomy, and culture. Paris is home to iconic landmarks like the Eiffel Tower, Louvre Museum, and Notre-Dame Cathedral. It's also a major political and economic hub in Europe.

> Finished chain.
```

### What Just Happened?
1. **ChatOpenAI**: Connects to GPT-4 API
2. **initialize_agent**: Creates an agent (decision-making system)
3. **AgentType.ZERO_SHOT_REACT_DESCRIPTION**: Agent type (more on this below)
4. **verbose=True**: Shows agent's reasoning steps (useful for debugging)
5. **agent.run()**: Sends query, gets response

### Understanding Agent Types

LangChain offers several agent types. Choose based on your needs:

| Agent Type | When to Use | Example |
|-----------|-------------|---------|
| **ZERO_SHOT_REACT_DESCRIPTION** | General purpose, no examples needed | "Answer questions about anything" |
| **CONVERSATIONAL_REACT_DESCRIPTION** | Multi-turn conversations with memory | "Chatbot that remembers previous messages" |
| **STRUCTURED_CHAT_ZERO_SHOT_REACT_DESCRIPTION** | Complex tool inputs (JSON, multi-param) | "Tool that accepts {user_id, action, data}" |
| **OPENAI_FUNCTIONS** | OpenAI's function calling (fastest, most reliable) | "Call APIs, execute tools with GPT-4" |

**For this tutorial, we'll use:**
- **ZERO_SHOT_REACT_DESCRIPTION** (Part 1-2): Simple, beginner-friendly
- **CONVERSATIONAL_REACT_DESCRIPTION** (Part 3): When we add memory
- **OPENAI_FUNCTIONS** (Part 4): Production-grade (fastest, cheapest)

### Customizing Your Agent

Modify behavior with parameters:
```python
llm = ChatOpenAI(
    model="gpt-4-turbo",
    temperature=0.7,       # 0 = deterministic, 1 = creative
    max_tokens=500,        # Limit response length
    model_kwargs={
        "top_p": 0.9,      # Nucleus sampling (diversity)
        "frequency_penalty": 0.5,  # Reduce repetition
    }
)
```

**Temperature guide:**
- **0.0-0.3**: Factual tasks (math, data extraction, code)
- **0.4-0.7**: Balanced (most use cases)
- **0.8-1.0**: Creative tasks (storytelling, brainstorming)

## Part 2: Adding Tools (Search, Calculate, File Access)

A basic agent is just a fancy chatbot. **Tools make agents useful**—they can search the web, perform calculations, access files, and execute code.

### Step 2.1: Understanding Tools

A **tool** is any function your agent can call. Examples:
- **Search tool**: Google search, Wikipedia lookup
- **Calculator tool**: Math operations
- **File tool**: Read/write files
- **API tool**: Call external APIs (weather, stock prices, CRM)
- **Code executor**: Run Python code

**How tools work:**
1. Agent receives user query
2. Agent decides which tool(s) to use
3. Agent calls tool(s) with appropriate inputs
4. Agent reads tool outputs
5. Agent formulates final response

### Step 2.2: Build a Calculator Tool

Create `calculator_tool.py`:
```python
from langchain.agents import Tool
from langchain.agents import initialize_agent, AgentType
from langchain_openai import ChatOpenAI
import math
import re

# Simple calculator function
def calculate(expression: str) -> str:
    """
    Evaluates a mathematical expression.
    Input: Math expression as string (e.g., "2 + 2", "sqrt(16)", "10 ** 2")
    Output: Result as string
    """
    try:
        # Security: Only allow math operations (no eval of arbitrary code)
        allowed = set("0123456789+-*/().** ")
        if not all(c in allowed or c.isspace() for c in expression.replace("sqrt", "").replace("math.", "")):
            return "Error: Invalid characters in expression"
        
        # Replace sqrt with math.sqrt
        expression = expression.replace("sqrt", "math.sqrt")
        
        # Evaluate safely
        result = eval(expression, {"__builtins__": {}, "math": math})
        return f"Result: {result}"
    except Exception as e:
        return f"Error: {str(e)}"

# Create tool
calculator_tool = Tool(
    name="Calculator",
    func=calculate,
    description="Useful for mathematical calculations. Input should be a valid math expression like '2+2' or 'sqrt(16)'. Use Python syntax."
)

# Initialize agent with calculator
llm = ChatOpenAI(model="gpt-4-turbo", temperature=0)
agent = initialize_agent(
    tools=[calculator_tool],
    llm=llm,
    agent=AgentType.ZERO_SHOT_REACT_DESCRIPTION,
    verbose=True
)

# Test queries
queries = [
    "What is 157 * 293?",
    "Calculate the square root of 12345",
    "If I invest $10,000 at 7% annual return for 10 years, how much will I have? Use formula: P * (1 + r)^t"
]

for query in queries:
    print(f"\n{'='*60}")
    print(f"Query: {query}")
    print('='*60)
    response = agent.run(query)
    print(f"Response: {response}\n")
```

**Run it:**
```bash
python calculator_tool.py
```

**Expected output:**
```
==============================================================
Query: What is 157 * 293?
==============================================================

> Entering new AgentExecutor chain...
I should use the Calculator tool to compute this.

Action: Calculator
Action Input: 157 * 293

Result: 46001

Final Answer: 46,001

> Finished chain.
Response: 46,001
```

### What Changed?
1. **Tool definition**: Created `calculate()` function + wrapped in `Tool()`
2. **Tool description**: Agent reads this to decide when to use the tool (critical—be specific!)
3. **Agent reasoning**: Agent now has a "thought → action → observation → final answer" loop

### Step 2.3: Add Web Search Tool

Install search library:

Create `search_agent.py`:
```python
from langchain.agents import Tool, initialize_agent, AgentType
from langchain_openai import ChatOpenAI
from duckduckgo_search import DDGS

def search_web(query: str) -> str:
    """
    Searches the web using DuckDuckGo.
    Input: Search query (e.g., "latest AI news")
    Output: Top 3 search results
    """
    try:
        ddgs = DDGS()
        results = ddgs.text(query, max_results=3)
        
        if not results:
            return "No results found"
        
        output = "Search results:\n\n"
        for i, result in enumerate(results, 1):
            output += f"{i}. {result['title']}\n"
            output += f"   {result['body'][:200]}...\n"
            output += f"   URL: {result['href']}\n\n"
        
        return output
    except Exception as e:
        return f"Search error: {str(e)}"

# Create search tool
search_tool = Tool(
    name="WebSearch",
    func=search_web,
    description="Searches the web for current information. Use this when you need up-to-date facts, news, or information not in your training data. Input should be a search query."
)

# Calculator tool from before
def calculate(expression: str) -> str:
    import math
    try:
        expression = expression.replace("sqrt", "math.sqrt")
        result = eval(expression, {"__builtins__": {}, "math": math})
        return f"Result: {result}"
    except Exception as e:
        return f"Error: {str(e)}"

calculator_tool = Tool(
    name="Calculator",
    func=calculate,
    description="Performs mathematical calculations. Input: math expression (e.g., '2+2', 'sqrt(16)')."
)

# Initialize agent with both tools
llm = ChatOpenAI(model="gpt-4-turbo", temperature=0)
agent = initialize_agent(
    tools=[search_tool, calculator_tool],
    llm=llm,
    agent=AgentType.ZERO_SHOT_REACT_DESCRIPTION,

# Test multi-tool query
query = """
```

### Step 2.4: File Access Tool

Create `file_agent.py`:
```python
from langchain.agents import Tool, initialize_agent, AgentType
from langchain_openai import ChatOpenAI
import os

def read_file(filepath: str) -> str:
    """
    Reads content from a file.
    Input: File path (e.g., 'data.txt', 'report.md')
    Output: File contents
    """
    try:
        with open(filepath, 'r', encoding='utf-8') as f:
            content = f.read()
        return f"File content ({len(content)} characters):\n\n{content}"
    except FileNotFoundError:
        return f"Error: File '{filepath}' not found"
    except Exception as e:
        return f"Error reading file: {str(e)}"

def write_file(input_str: str) -> str:
    """
    Writes content to a file.
    Input: Format "filepath|content" (e.g., "output.txt|Hello world")
    Output: Success/error message
    """
    try:
        filepath, content = input_str.split("|", 1)
        with open(filepath, 'w', encoding='utf-8') as f:
            f.write(content)
        return f"Successfully wrote {len(content)} characters to '{filepath}'"
    except ValueError:
        return "Error: Input must be in format 'filepath|content'"
    except Exception as e:
        return f"Error writing file: {str(e)}"

def list_files(directory: str = ".") -> str:
    """
    Lists files in a directory.
    Input: Directory path (default: current directory)
    Output: List of files
    """
    try:
        files = os.listdir(directory)
        return f"Files in '{directory}':\n" + "\n".join(f"- {f}" for f in files)
    except Exception as e:
        return f"Error listing files: {str(e)}"

# Create tools
read_tool = Tool(name="ReadFile", func=read_file, description="Reads content from a file. Input: filepath")
write_tool = Tool(name="WriteFile", func=write_file, description="Writes content to a file. Input: 'filepath|content'")
list_tool = Tool(name="ListFiles", func=list_files, description="Lists files in a directory. Input: directory path")

# Initialize agent
llm = ChatOpenAI(model="gpt-4-turbo", temperature=0)
agent = initialize_agent(
    tools=[read_tool, write_tool, list_tool],
    llm=llm,
    agent=AgentType.ZERO_SHOT_REACT_DESCRIPTION,
    verbose=True,
    max_iterations=5  # Prevent infinite loops
)

# Test: Create file, read it, modify it
test_query = """
Create a file called 'todo.txt' with these tasks:
1. Buy groceries
2. Call dentist
3. Finish project report

Then read the file to confirm it was created correctly.
"""

response = agent.run(test_query)
print(f"\n\nFinal Response:\n{response}")
```

**Security warning**: File tools are powerful but risky. In production:
- **Whitelist directories**: Only allow access to specific folders
- **Validate inputs**: Check for path traversal attacks (`../../etc/passwd`)
- **Limit file size**: Prevent reading/writing huge files
- **Audit logs**: Track all file operations

## Part 3: Adding Memory (Remember Past Conversations)

Right now, your agent is **stateless**—it forgets everything after each conversation. Memory makes agents useful for:
- **Chatbots**: Remember user preferences, past questions
- **Personal assistants**: Track ongoing projects, todos
- **Customer support**: Reference past tickets, customer history

### Step 3.1: Conversation Memory

Create `memory_agent.py`:
```python
from langchain.agents import initialize_agent, AgentType, Tool
from langchain_openai import ChatOpenAI
from langchain.memory import ConversationBufferMemory

# Simple greeting tool (to demonstrate memory)
def greet_user(name: str) -> str:
    return f"Hello, {name}! Nice to meet you."

greet_tool = Tool(
    name="Greeting",
    func=greet_user,
    description="Greets a user by name. Input: user's name"
)

# Initialize memory
memory = ConversationBufferMemory(
    memory_key="chat_history",
    return_messages=True
)

# Initialize agent with memory
llm = ChatOpenAI(model="gpt-4-turbo", temperature=0.7)
agent = initialize_agent(
    tools=[greet_tool],
    llm=llm,
    agent=AgentType.CONVERSATIONAL_REACT_DESCRIPTION,  # Note: Different agent type for memory
    memory=memory,
    verbose=True
)

# Simulate conversation
conversations = [
    "Hi, my name is Alice.",
    "What's my name?",
    "I like pizza. Remember that.",
    "What do I like to eat?",
    "What did we talk about earlier?"
]

for i, user_input in enumerate(conversations, 1):
    print(f"\n{'='*60}")
    print(f"Turn {i}: {user_input}")
    print('='*60)
    response = agent.run(user_input)
    print(f"Agent: {response}")
```

**Run it:**
```bash
python memory_agent.py
```

**Expected output:**
```
Turn 1: Hi, my name is Alice.
Agent: Hello, Alice! Nice to meet you.

Turn 2: What's my name?
Agent: Your name is Alice.

Turn 3: I like pizza. Remember that.
Agent: Got it! I'll remember that you like pizza.

Turn 4: What do I like to eat?
Agent: You like pizza!

Turn 5: What did we talk about earlier?
Agent: We talked about your name (Alice) and that you like pizza.
```

### What Changed?
1. **ConversationBufferMemory**: Stores all messages (user + agent) in memory
2. **AgentType.CONVERSATIONAL_REACT_DESCRIPTION**: Agent type designed for multi-turn conversations
3. **memory_key="chat_history"**: Agent can access past messages via this key

### Step 3.2: Memory Types (Choose the Right One)

LangChain offers several memory types. Choose based on your needs:

#### 1. ConversationBufferMemory (Simple, Full History)
**Stores**: Every message
**Use case**: Short conversations (< 10 messages)
**Pros**: Simple, no data loss
**Cons**: Token usage grows infinitely (expensive for long conversations)

```python
from langchain.memory import ConversationBufferMemory

memory = ConversationBufferMemory(
    memory_key="chat_history",
    return_messages=True
)
```

#### 2. ConversationBufferWindowMemory (Last N Messages)
**Stores**: Last N messages only
**Use case**: Long conversations, only recent context matters
**Pros**: Fixed token usage
**Cons**: Forgets old context

```python
from langchain.memory import ConversationBufferWindowMemory

memory = ConversationBufferWindowMemory(
    k=5,  # Remember last 5 messages
    memory_key="chat_history",
    return_messages=True
)
```

#### 3. ConversationSummaryMemory (Summarize Old Messages)
**Stores**: Recent messages + summary of old messages
**Use case**: Long conversations, need context from beginning
**Pros**: Balances detail and cost
**Cons**: Summary may lose nuance

```python
from langchain.memory import ConversationSummaryMemory

memory = ConversationSummaryMemory(
    llm=ChatOpenAI(model="gpt-3.5-turbo"),  # Use cheaper model for summaries
    memory_key="chat_history",
    return_messages=True
)
```

#### 4. ConversationEntityMemory (Remember Specific Facts)
**Stores**: Extracted entities (names, preferences, facts)
**Use case**: Customer support, personal assistants
**Pros**: Efficient, focuses on important facts
**Cons**: May miss context

```python
from langchain.memory import ConversationEntityMemory

memory = ConversationEntityMemory(
    llm=ChatOpenAI(model="gpt-4-turbo"),
    memory_key="chat_history",
    return_messages=True
)
```

**Comparison table:**

| Memory Type | Token Usage | Context Quality | Best For |
|------------|-------------|-----------------|----------|
| Buffer | High (grows infinitely) | Perfect | Short conversations |
| Window | Low (fixed) | Recent only | Chatbots, support |
| Summary | Medium (fixed) | Good | Long-running assistants |
| Entity | Low | Focused facts | Customer data, preferences |

### Step 3.3: Persistent Memory (Save to Database)

Previous examples store memory in RAM—restarting the script loses everything. For production, save to database:

```python
from langchain.memory import ConversationBufferMemory
from langchain.memory.chat_message_histories import FileChatMessageHistory

# Save to JSON file (simple, no database needed)
history = FileChatMessageHistory("conversation_history.json")

memory = ConversationBufferMemory(
    chat_memory=history,
    memory_key="chat_history",
    return_messages=True
)

# Now memory persists across script runs!
```

**For production** (PostgreSQL, Redis, MongoDB):
```python
# PostgreSQL example
from langchain.memory.chat_message_histories import PostgresChatMessageHistory

history = PostgresChatMessageHistory(
    connection_string="postgresql://user:pass@localhost/db",
    session_id="user_12345"  # Unique per user
)

memory = ConversationBufferMemory(
    chat_memory=history,
    memory_key="chat_history",
    return_messages=True
)
```

## Part 4: Multi-Agent Systems (Collaborative Agents)

Single agents are powerful, but complex tasks require **multiple specialized agents** working together:
- **Research Agent**: Searches web, gathers information
- **Analyst Agent**: Analyzes data, identifies patterns
- **Writer Agent**: Writes reports, summaries
- **Coder Agent**: Writes code, fixes bugs

### Step 4.1: Simple Multi-Agent System

Create `multi_agent.py`:
```python
from langchain_openai import ChatOpenAI
from langchain.agents import initialize_agent, AgentType, Tool
from typing import Dict

# --- Agent 1: Researcher ---
def research_topic(topic: str) -> str:
    """Simulates web research (in real system, would call search API)"""
    # Mock data (replace with real web search in production)
    research_db = {
        "AI agents": "AI agents are autonomous systems that can perceive, reason, and act. Key frameworks: LangChain, AutoGPT, BabyAGI. Major companies: OpenAI, Anthropic, Google.",
        "climate change": "Global temperatures risen 1.1°C since pre-industrial. Paris Agreement aims to limit to 1.5°C. Major challenges: fossil fuels, deforestation.",
    }
    return research_db.get(topic.lower(), f"No research data found for '{topic}'")

research_tool = Tool(
    name="Research",
    func=research_topic,
    description="Researches a topic and returns key facts. Input: topic name"
)

researcher_llm = ChatOpenAI(model="gpt-4-turbo", temperature=0)
researcher = initialize_agent(
    tools=[research_tool],
    llm=researcher_llm,
    agent=AgentType.ZERO_SHOT_REACT_DESCRIPTION,
    verbose=False
)

# --- Agent 2: Analyst ---
def analyze_data(data: str) -> str:
    """Analyzes data and identifies key insights"""
    # In production, this would perform statistical analysis, ML predictions, etc.
    word_count = len(data.split())
    return f"Analysis: Data contains {word_count} words. Key terms: {', '.join(set(data.split()[:5]))}"

analyze_tool = Tool(
    name="Analyze",
    func=analyze_data,
    description="Analyzes data and extracts insights. Input: data to analyze"
)

analyst_llm = ChatOpenAI(model="gpt-4-turbo", temperature=0)
analyst = initialize_agent(
    tools=[analyze_tool],
    llm=analyst_llm,
    agent=AgentType.ZERO_SHOT_REACT_DESCRIPTION,
    verbose=False
)

# --- Agent 3: Writer ---
def write_report(topic: str, content: str) -> str:
    """Formats content into a report"""
    return f"""
# Report: {topic}

## Summary
{content[:200]}...

## Detailed Findings
{content}

---
*Generated by AI Agent System*
"""

write_tool = Tool(
    name="WriteReport",
    func=write_report,
    description="Formats content into a professional report. Input: 'topic|content'"
)

writer_llm = ChatOpenAI(model="gpt-4-turbo", temperature=0.7)
writer = initialize_agent(
    tools=[write_tool],
    llm=writer_llm,
    agent=AgentType.ZERO_SHOT_REACT_DESCRIPTION,
    verbose=False
)

# --- Orchestrator: Coordinates all agents ---
def orchestrator(task: str) -> str:
    """
    Coordinates multiple agents to complete a task.
    Example task: "Research AI agents and write a report"
    """
    print(f"\n🤖 Orchestrator received task: {task}\n")
    
    # Step 1: Research
    print("📚 Step 1: Research Agent working...")
    research_result = researcher.run(f"Research the topic: {task}")
    print(f"   Research complete: {len(research_result)} characters")
    
    # Step 2: Analyze
    print("\n📊 Step 2: Analyst Agent working...")
    analysis_result = analyst.run(f"Analyze this data: {research_result}")
    print(f"   Analysis complete: {analysis_result}")
    
    # Step 3: Write
    print("\n✍️  Step 3: Writer Agent working...")
    report = writer.run(f"{task}|{research_result}\n\nAnalysis: {analysis_result}")
    print("   Report complete!")
    
    return report

# --- Test the system ---
task = "AI agents"
final_report = orchestrator(task)
print("\n" + "="*60)
print("FINAL REPORT")
print("="*60)
print(final_report)
```

**Run it:**
```bash
python multi_agent.py
```

**Expected output:**

### Step 4.2: Advanced Pattern (Agent Communication)

Instead of orchestrator calling agents sequentially, agents can **communicate directly**:

```python
from langgraph.graph import StateGraph, END
from typing import TypedDict, Annotated
import operator

# Define shared state (agents communicate via this)
class AgentState(TypedDict):
    task: str
    research_data: str
    analysis: str
    final_report: str

# Research agent
def research_node(state: AgentState) -> AgentState:
    print("🔍 Research Agent working...")
    # Simulate research
    state["research_data"] = f"Research findings about: {state['task']}"
    return state

# Analyst agent
def analyze_node(state: AgentState) -> AgentState:
    print("📊 Analyst Agent working...")
    # Simulate analysis
    state["analysis"] = f"Analysis of: {state['research_data']}"
    return state

# Writer agent
def write_node(state: AgentState) -> AgentState:
    print("✍️  Writer Agent working...")
    # Simulate writing
    state["final_report"] = f"Report:\n{state['research_data']}\n\n{state['analysis']}"
    return state

# Build workflow graph
workflow = StateGraph(AgentState)
workflow.add_node("research", research_node)
workflow.add_node("analyze", analyze_node)
workflow.add_node("write", write_node)

# Define flow: research → analyze → write → end
workflow.set_entry_point("research")
workflow.add_edge("research", "analyze")
workflow.add_edge("analyze", "write")
workflow.add_edge("write", END)

# Compile and run
app = workflow.compile()
result = app.invoke({"task": "AI agents"})
print("\n" + result["final_report"])
```

**Why use graphs?**
- **Parallel execution**: Multiple agents run simultaneously (faster)
- **Conditional routing**: Agent A → Agent B OR Agent C (based on output)
- **Loops**: Agents can iterate until quality threshold met

```python
from langchain.agents import initialize_agent, AgentType

def safe_agent_run(agent, query: str, max_retries: int = 3):
    """
    Runs agent with error handling and retries.
    """
    for attempt in range(max_retries):
        try:
            logger.info(f"Attempt {attempt + 1}: Running query: {query}")
            response = agent.run(query)
            logger.info(f"Success: {response[:100]}...")
            return response
        except Exception as e:
            logger.error(f"Attempt {attempt + 1} failed: {str(e)}")
            if attempt == max_retries - 1:
                return f"Error: Agent failed after {max_retries} attempts. Last error: {str(e)}"
```

## Part 6: Common Mistakes & Debugging

### Mistake 1: Tool Description Too Vague

❌ **Bad:**
```python
Tool(
    name="Helper",
    func=my_function,
    description="Helps with stuff"
)
```

✅ **Good:**
```python
Tool(
    name="WebSearch",
    func=search_web,
    description="Searches the web for current information. Use when you need up-to-date facts, news, or data not in your training data. Input: search query (e.g., 'latest AI news', 'population of France')."
)
```

**Why it matters**: Agent decides which tool to use based ONLY on description. Vague description = agent never uses the tool.

### Mistake 2: Infinite Agent Loops

Agent keeps calling tools without reaching final answer. **Fix:**
```python
agent = initialize_agent(
    tools=tools,
    llm=llm,
    agent=AgentType.ZERO_SHOT_REACT_DESCRIPTION,
    max_iterations=10,  # Force stop after 10 steps
    early_stopping_method="generate"  # Generate final answer even if not finished
)
```

### Mistake 3: Not Handling API Rate Limits

OpenAI rate limits: 500 requests/minute (free tier). **Fix:**
```python
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    model="gpt-4-turbo",
    request_timeout=30,  # Timeout after 30 seconds
    max_retries=3  # Retry failed requests
)
```

**For high volume**, implement exponential backoff:
```python
import time
from openai import RateLimitError

def call_agent_with_backoff(agent, query, max_retries=5):
    for i in range(max_retries):
        try:
            return agent.run(query)
        except RateLimitError:
            wait_time = 2 ** i  # 1s, 2s, 4s, 8s, 16s
            print(f"Rate limited. Waiting {wait_time}s...")
            time.sleep(wait_time)
    raise Exception("Max retries exceeded")
```

### Mistake 4: Exposing API Keys in Code

❌ **Never:**
```python
os.environ["OPENAI_API_KEY"] = "sk-abc123"  # Hard-coded key
```

✅ **Always:**
```python
from dotenv import load_dotenv
import os

load_dotenv()  # Loads from .env file
api_key = os.getenv("OPENAI_API_KEY")

if not api_key:
    raise ValueError("OPENAI_API_KEY not found in environment")
```

### Mistake 5: No Input Validation on Tools

User input goes directly to tools (security risk). **Fix:**
```python
def safe_file_read(filepath: str) -> str:
    # Validate input
    if ".." in filepath:
        return "Error: Path traversal detected"
    
    allowed_dir = "/home/user/safe_dir"
    full_path = os.path.abspath(filepath)
    
    if not full_path.startswith(allowed_dir):
        return "Error: Access denied (outside allowed directory)"
    
    # Now safe to read
    with open(full_path, 'r') as f:
        return f.read()
```

## Part 8: Advanced Topics (Where to Go Next)

### 1. RAG (Retrieval-Augmented Generation)
Train your agent on custom data (docs, policies, codebases):
```python
from langchain.vectorstores import Chroma
from langchain.embeddings import OpenAIEmbeddings
from langchain.document_loaders import TextLoader

# Load your documents
loader = TextLoader("company_policies.txt")
documents = loader.load()

# Create vector database
embeddings = OpenAIEmbeddings()
vectorstore = Chroma.from_documents(documents, embeddings)

# Create retrieval tool
retriever_tool = Tool(
    name="PolicySearch",
    func=lambda q: vectorstore.similarity_search(q, k=3),
    description="Searches company policies. Use for questions about rules, procedures, or guidelines."
)
```

**Cost**: ~$0.0004 per 1,000 words (one-time indexing cost)

### 2. Fine-Tuning (Custom Behavior)
Make GPT-4 behave exactly how you want:
```bash
# Prepare training data (100-1000 examples)
{"messages": [{"role": "system", "content": "You are a helpful assistant."}, {"role": "user", "content": "How do I reset my password?"}, {"role": "assistant", "content": "Click 'Forgot Password' on the login page..."}]}

# Fine-tune (via OpenAI API)
openai api fine_tunes.create -t training_data.jsonl -m gpt-4-turbo
```

**Cost**: ~$8 per 1M tokens training, ~$0.06 per 1K tokens inference (3x base GPT-4)

**When to fine-tune:**
- Agent needs domain-specific knowledge (medical, legal, technical)
- Specific tone/style required (formal, casual, brand voice)
- Sensitive data (can't send to OpenAI)

### 3. Local LLMs (No OpenAI Dependency)
Run models locally (free, private):
```bash
# Install Ollama
curl -fsSL https://ollama.com/install.sh | sh

# Download model (e.g., Llama 3)
ollama pull llama3

# Use in LangChain
from langchain.llms import Ollama

llm = Ollama(model="llama3")

```

**Pros**: Free, private, no rate limits
**Cons**: Slower, lower quality than GPT-4, requires GPU

### 4. Guardrails (Safety & Compliance)
Prevent agents from saying/doing harmful things:
```python
from guardrails.hub import ToxicLanguage
from guardrails import Guard

# Create guardrail
guard = Guard().use(ToxicLanguage, threshold=0.5, validation_method="sentence")

# Wrap agent
def safe_agent_run(agent, query):
    response = agent.run(query)
    validated_response = guard.validate(response)
    return validated_response
```

**Common guardrails:**
- **Toxicity filter**: Block offensive language
- **PII detection**: Remove names, SSNs, credit cards
- **Hallucination check**: Verify facts against knowledge base
- **Budget limit**: Stop if cost exceeds $X

## Bonus: Complete Production Agent Template

Save this as `production_agent_template.py` for your next project:

```python
"""
Production AI Agent Template
- Error handling
- Cost tracking
- Logging
- Memory
- Multiple tools
- Health checks
"""

from langchain_openai import ChatOpenAI
from langchain.agents import initialize_agent, AgentType, Tool
from langchain.memory import ConversationBufferWindowMemory
from langchain.callbacks import get_openai_callback
from dotenv import load_dotenv
import logging
import os

# --- Configuration ---
load_dotenv()
logging.basicConfig(level=logging.INFO)
logger = logging.getLogger(__name__)

# --- Tools Definition ---
def example_tool(input_text: str) -> str:
    """Example tool - replace with your own"""
    return f"Processed: {input_text}"

tools = [
    Tool(
        name="ExampleTool",
        func=example_tool,
        description="Example tool description. Replace this."
    )
]

# --- Agent Setup ---
def create_agent():
    """Creates and returns configured agent"""
    llm = ChatOpenAI(
        model="gpt-4-turbo",
        temperature=0.7,
        request_timeout=30,
        max_retries=3
    )
    
    memory = ConversationBufferWindowMemory(
        k=5,
        memory_key="chat_history",
        return_messages=True
    )
    
    agent = initialize_agent(
        tools=tools,
        llm=llm,
        agent=AgentType.CONVERSATIONAL_REACT_DESCRIPTION,
        memory=memory,
        verbose=True,
        max_iterations=10,
        early_stopping_method="generate"
    )
    
    return agent

# --- Safe Execution ---
def run_agent(agent, query: str, max_retries: int = 3):
    """Runs agent with error handling and cost tracking"""
    for attempt in range(max_retries):
        try:
            logger.info(f"Attempt {attempt + 1}: {query}")
            
            with get_openai_callback() as cb:
                response = agent.run(query)
                
                # Log cost
                logger.info(f"Cost: ${cb.total_cost:.4f} | Tokens: {cb.total_tokens}")
                
                # Alert if expensive
                if cb.total_cost > 0.50:
                    logger.warning(f"High cost detected: ${cb.total_cost:.4f}")
                
                return {
                    "response": response,
                    "cost": cb.total_cost,
                    "tokens": cb.total_tokens
                }
                
        except Exception as e:
            logger.error(f"Attempt {attempt + 1} failed: {str(e)}")
            if attempt == max_retries - 1:
                return {
                    "error": str(e),
                    "response": "Agent failed. Please try again."
                }

# --- Main ---
if __name__ == "__main__":
    agent = create_agent()
    
    # Test queries
    queries = [
        "Hello, how are you?",
        "What's 157 * 293?",
        "Tell me a joke"
    ]
    
    for query in queries:
        print(f"\n{'='*60}")
        print(f"Query: {query}")
        print('='*60)
        result = run_agent(agent, query)
        print(f"Response: {result.get('response')}")
        if 'cost' in result:
            print(f"Cost: ${result['cost']:.4f}")
```
