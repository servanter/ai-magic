## Chapter 2: Prompt Engineering Fundamentals

### 2.1 The Anatomy of High-Converting Marketing Prompts

Professional prompt structure follows a proven formula:

**FRAMEWORK: SUBJECT + CONTEXT + STYLE + TECHNICAL + CONSTRAINTS**

**Example Breakdown:**

Poor prompt:
```
"Product on a table"
```

Professional prompt:
```
"Professional product photography of [wireless earbuds] on [minimalist marble surface], 
[soft morning light through window], [premium lifestyle context with coffee cup and 
notebook in background], [clean white background], [studio lighting setup with key light 
at 45 degrees], [shallow depth of field f/2.8], [commercial photography style], 
[high-end tech aesthetic], [shot with 85mm lens], [8K resolution], [photorealistic]"
```

**Why this works:**
- Subject (wireless earbuds): Clear focal point
- Context (marble surface, coffee, notebook): Lifestyle association
- Style (premium, minimalist): Brand positioning
- Technical (lighting, DOF, lens): Professional quality
- Constraints (8K, photorealistic): Output specifications

### 2.2 The 10 Essential Prompt Components

Build every marketing image prompt with these elements:

**1. Subject Definition (Required)**
```
"Modern smartphone [specific model details]"
"Professional woman age 30-35 [demographic clarity]"
"Eco-friendly packaging [product category]"
```

**2. Action/Pose (If applicable)**
```
"Looking directly at camera with confident smile"
"Holding product at eye level"
"Walking through urban environment"
```

**3. Environment/Setting**
```
"In contemporary office with floor-to-ceiling windows"
"Against solid color backdrop [specify color]"
"In bright Scandinavian-style kitchen"
```

**4. Lighting Direction**
```
"Soft window light from left"
"Dramatic rim lighting"
"Evenly lit studio setup"
```

**5. Color Palette**
```
"Dominated by blue tones [#0066CC]"
"Warm autumn colors palette"
"Monochromatic scheme with purple accents"
```

**6. Mood/Emotion**
```
"Aspirational and inspiring"
"Calm and reassuring"
"Energetic and dynamic"
```

**7. Composition**
```
"Rule of thirds with subject in right third"
"Centered composition with symmetry"
"Asymmetric balance with negative space on left"
```

**8. Camera Settings Simulation**
```
"Shot with 50mm lens"
"Shallow depth of field f/1.8"
"Wide angle 24mm perspective"
```

**9. Style Reference**
```
"Apple product photography style"
"Editorial fashion photography aesthetic"
"Documentary-style authenticity"
```

**10. Output Specifications**
```
"High resolution 4K"
"Horizontal 16:9 aspect ratio"
"Photorealistic rendering"
```

### 2.4 Advanced Prompt Techniques

**Negative Prompting (Tell the AI what NOT to include):**
```
Prompt: "Professional headshot for corporate website"
Negative prompt: "casual clothing, busy background, harsh shadows, 
overexposed, blurry, amateur lighting, cluttered, distorted face"
```

**Weighted Keywords (Emphasizing priorities):**
```
"Product photography with [premium quality:1.5], [luxury aesthetic:1.3], 
minimal background, soft lighting"
```
(Numbers indicate relative importance)

**Style Blending:**
```
"Combine [Apple product photography aesthetic:0.6] with [editorial magazine 
style:0.4] for tech accessory marketing image"
```

**Iterative Refinement Process:**
1. Start with basic prompt → Generate first version
2. Analyze output → Identify issues (lighting too harsh, composition off, etc.)
3. Add specific corrections → Regenerate
4. Repeat 2-3 times until achieving desired result

## Chapter 3: Building Brand Consistency Systems

### 3.1 Creating Your Brand Visual DNA

Brand consistency is the number one challenge when scaling AI-generated marketing images. Here's how professionals solve it:

**Step 1: Define Core Brand Elements**

Create a "Brand Visual Specification" document:

```
BRAND: [Your Company Name]
DATE: [Updated monthly]

COLOR PALETTE:
- Primary: #0066CC (Brand Blue)
- Secondary: #FF6B35 (Accent Orange)
- Neutral: #F5F5F5 (Background Gray)
- Text: #333333 (Dark Gray)

IMAGERY STYLE:
- Overall mood: Professional yet approachable
- Color temperature: Slightly warm (not cold clinical)
- Contrast: Medium-high for visibility
- Composition: Clean with breathing room

SUBJECT PREFERENCES:
- Demographics: Diverse representation, ages 25-50
- Settings: Modern offices, home offices, urban environments
- Avoid: Overly staged stock photo looks, cliché poses

TECHNICAL STANDARDS:
- Resolution: 3000x3000px minimum
- Format: JPG for photos, PNG for graphics with transparency
- File size: Under 500KB for web
- Color space: sRGB
```

**Step 2: Create Reference Image Sets**

Build a library of 10-15 "golden reference" images that perfectly represent your brand:

- 3-5 images showing ideal color palette application
- 3-5 images demonstrating preferred composition style
- 3-5 images illustrating brand mood/emotion
- 2-3 images showing unacceptable examples (what to avoid)

**Step 3: Develop Prompt Templates**

Create standardized prompt beginnings that enforce brand consistency:

```
BASE PROMPT TEMPLATE:
"[Your specific subject], photographed in [brand-aligned style], 
[brand color palette incorporated], professional marketing photography, 
clean composition with negative space, [brand mood descriptor], 
modern and polished, optimized for [platform], high quality"
```

Every team member starts with this base and customizes only the subject.

### 3.2 Color Consistency Techniques

**Method 1: Explicit Color Specification**
```
"Dominant color scheme: Blue (#0066CC) 60%, White 30%, Orange (#FF6B35) 10% 
as accent, professional marketing image"
```

**Method 2: Reference Image Integration**
Many platforms (AImage, Midjourney, Leonardo) allow uploading reference images:
```
"Using reference image color_palette.jpg, create [subject] maintaining 
the same color harmony and tone"
```

**Method 3: Post-Generation Color Grading**
For critical brand assets, apply consistent color grading:
- Use tools like Photoshop Camera Raw filters
- Create and save brand-specific preset adjustments
- Apply the same preset to all AI-generated images before publishing

**Pro Tip:** Create a "Brand Color Checker" card (similar to photography gray cards) with your exact brand colors, include it in reference images to train the AI.

### 3.3 Logo and Text Overlay Best Practices

AI-generated images rarely produce readable text natively, so plan for post-generation overlay:

**Composition for Logo Placement:**
```
Prompt: "...with clean open space in [top right / bottom left] corner 
for logo placement, uncluttered zone, simple background in that area"
```

**Safe Zones for Text:**
```
Prompt: "...with horizontal composition, subject positioned in left 
two-thirds, right third kept as neutral background for text overlay"
```

**Contrast Preparation:**
```
Prompt: "...background transitions to darker shade in [location] area 
for white text overlay, natural gradient"
```

**Workflow Integration:**
1. Generate base image with planned text zones
2. Import into Canva/Figma/Photoshop
3. Add text/logos using brand templates
4. Export final marketing-ready asset

```
Week 4: Scale winning formula across campaigns
```

### 5.4 Product Integration Without Looking Fake

**Challenge:** AI-generated products often look synthetic or inconsistent.

**Solution: The Layered Approach**

**Method 1: Real Product + AI Environment**
1. Photograph your actual product (professional setup)
2. Remove background using tools like Remove.bg
3. Generate perfect environment scene with AI
4. Composite product into AI-generated scene

**Method 2: AI Product with Photo-Realism Enforcement**
```
Prompt: "[Your product with exact specifications], photorealistic rendering, 
product photography quality, accurate materials and textures, physically 
accurate lighting, not CGI-looking, commercial product photography style, 
shot with medium format camera"
```

**Method 3: Style Transfer from Real Product Photos**
```
Upload reference: Your actual product photo
Prompt: "Generate marketing scene using this product, maintain exact product 
appearance and lighting, place in [environment], keep product details identical"
```

**Quality Checklist:**
- Materials look physically accurate (metal reflects, fabric has texture)
- Lighting is consistent across product and environment
- Shadows and reflections match light sources
- Product proportions are realistic
- No artifacts or distortions on product details

### 5.5 Animation and Motion-Ready Assets

**Preparing for Video Marketing:**

Generate image sequences for animation:


## Chapter 6: Quality Control and Optimization

### 6.1 Technical Quality Checklist

Before publishing any AI-generated marketing image:

**Resolution and Sharpness:**
- [ ] Meets platform minimum resolution requirements
- [ ] No obvious pixelation or blur artifacts
- [ ] Details are crisp and clear (zoom to 100% to verify)
- [ ] Text-overlay areas are clean and undistorted

**Color Accuracy:**
- [ ] Colors match brand guidelines (use eyedropper tool)
- [ ] Proper white balance (no unwanted color casts)
- [ ] Sufficient contrast for accessibility (WCAG AA minimum)
- [ ] Colors display correctly on multiple devices

**Composition and Framing:**
- [ ] Subject properly positioned (rule of thirds or intentional centering)
- [ ] Adequate negative space for text/logo placement
- [ ] No important elements cut off at edges
- [ ] Visual hierarchy guides eye to key message

**Authenticity and Believability:**
- [ ] No obvious AI artifacts (extra fingers, distorted features)
- [ ] Lighting is physically plausible
- [ ] Shadows and reflections are consistent
- [ ] Proportions are accurate

**Brand Compliance:**
- [ ] Aligns with brand visual guidelines
- [ ] Appropriate tone and mood for brand personality
- [ ] No conflicting competitor products visible
- [ ] Suitable for target audience demographic

### 6.2 Common AI Artifacts and How to Fix Them

**Problem 1: Distorted Hands/Faces**

Fix strategies:
- **Prevention**: "Anatomically correct hands, proper finger count, realistic proportions"
- **Selective regeneration**: Use inpainting to regenerate only problem areas
- **Post-processing**: Minor touchups in Photoshop for small issues
- **Avoidance**: Compose images where hands/faces are less prominent

**Problem 2: Text/Numbers in Image (Usually Gibberish)**

Fix strategies:
- **Prevention**: "No text in image" in prompt
- **Removal**: Clone stamp or content-aware fill in Photoshop
- **Acceptance**: For background elements where unreadable text is okay

**Problem 3: Inconsistent Lighting**

Fix strategies:
- **Better prompt**: "Consistent lighting from [direction], single light source, coherent shadows"
- **Post-processing**: Adjust selective areas with dodge/burn tools
- **Reference images**: Provide lighting reference for AI to follow

**Problem 4: Unnatural Colors**

Fix strategies:
- **Color grading**: Apply consistent LUT or color correction
- **Specific guidance**: "Natural color palette, realistic saturation, not oversaturated"
- **Manual adjustment**: HSL adjustments in Lightroom/Photoshop

**Problem 5: Low Resolution Despite High Settings**

Fix strategies:
- **Upscaling**: Use AI upscalers (Topaz Gigapixel, Real-ESRGAN)
- **Better platform**: Some platforms have better native resolution outputs
- **Source quality**: Start with highest resolution your platform offers

### 6.3 File Optimization for Web Performance

**Balancing Quality and Load Time:**

Target file sizes:
- **Hero images**: 200-400KB
- **In-content images**: 100-200KB
- **Thumbnails**: 20-50KB
- **Background images**: 150-300KB

**Optimization Workflow:**

1. **Export from AI platform** at highest quality
2. **Resize to final dimensions** (don't serve oversized images)
3. **Compress** using tools like:
   - TinyPNG (automated compression)
   - ImageOptim (Mac)
   - Squoosh (web-based)
4. **Convert to WebP** for modern browsers (50-90% size reduction)
5. **Implement progressive loading** (low-res placeholder → high-res)

**Compression Settings:**
- JPEG quality: 80-85 for marketing images
- PNG: Use when transparency required
- WebP: Quality 80 is equivalent to JPEG 90-95

## Chapter 8: Ethical Considerations and Best Practices

### 8.1 Transparency and Disclosure

**When to Disclose AI-Generated Imagery:**

**Must disclose:**
- Any images representing real people (even AI-generated faces)
- Testimonial images (even if content is real, image must be)
- Before/after product results (if results are simulated)
- Documentary or news-style content

**Consider disclosing:**
- Artistic/conceptual marketing images
- Illustrative content (not claiming to be real)
- Background/environmental imagery

**Not required:**
- Abstract designs, patterns, graphics
- Clearly fantastical or surreal imagery
- Product-only shots (with AI-generated environments)

**Disclosure Language Examples:**
- "Image created with AI technology"
- "Illustrative rendering"
- "Conceptual visualization"

### 8.2 Representation and Diversity

**Responsible Representation:**

Do:
- Generate diverse representation across all campaigns
- Use specific inclusive prompts: "diverse representation, various ethnicities, different body types, range of ages"
- Review for stereotyping before publishing
- Consult DEI guidelines for your industry

Don't:
- Tokenize diversity (one diverse image among homogeneous set)
- Perpetuate stereotypes through prompts
- Use AI to avoid real representation (eventually feature real customers)
- Assume AI will automatically create diverse imagery

**Prompt Best Practices:**
```
Good: "Professional team meeting, diverse group of people various ethnicities 
and genders, inclusive workplace, authentic representation"

Avoid: "Professional team meeting, include one person of each race" 
(tokenizing)
```

### 8.3 Competitive and Legal Considerations

**Avoiding Copyright Issues:**

- Don't prompt for specific copyrighted characters/brands/artworks
- Avoid style references to living artists without permission
- Don't recreate competitor's distinctive brand imagery
- Check platform terms for commercial use rights

**Trademark Caution:**
```
Risky: "Smartphone in Apple style"
Safer: "Smartphone with minimalist design aesthetic"

Risky: "Running shoes inspired by Nike Air"
Safer: "Athletic running shoes with modern design"
```

**Model/Property Releases:**
AI-generated people don't need model releases, but:
- If AI references real people (even loosely), there may be legal gray areas
- For high-value campaigns, consult legal team
- Consider using AI-generated faces as placeholders, real people for final assets

### 8.4 Environmental Impact

**AI Generation Carbon Footprint:**

Reality check:
- One AI-generated image: ~0.3 kg CO₂ equivalent
- One traditional photoshoot: ~200-500 kg CO₂ (travel, equipment, studio energy)
- For high-volume marketing, AI is significantly lower environmental impact

**Best Practices:**
- Generate efficiently (refine prompts rather than brute-force generation)
- Use platforms with renewable energy commitments
- Balance: Use AI for volume, traditional for high-impact hero assets
- Consider carbon offset programs
